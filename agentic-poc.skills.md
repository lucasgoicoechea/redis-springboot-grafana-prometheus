# Agentic POC Skills

## skill: domain-analysis

- Purpose: understand the Spring Boot monitoring and caching context.
- Inputs: domain description, business objectives, non-functional requirements.
- Outputs: problem statement, value hypothesis, scope boundaries.

## skill: architecture-design

- Purpose: propose the service architecture and integration model.
- Inputs: problem statement, constraints, desired observability.
- Outputs: component diagram, data flow, deployment considerations.

## skill: integration-modeling

- Purpose: define Redis caching strategy and monitoring integration.
- Inputs: architecture design, functional requirements.
- Outputs: Redis policy, Prometheus scrape plan, Grafana dashboard outline.

## skill: spec-writing

- Purpose: write the technical specification for the POC.
- Inputs: domain analysis, architecture, integration model.
- Outputs: functional requirements, acceptance criteria, sample stack references.

## skill: task-planning

- Purpose: create the implementation backlog and milestones.
- Inputs: specification, architecture, priority signals.
- Outputs: ordered tasks, success criteria, delivery phases.

## skill: prompt-design

- Purpose: provide starter prompts for launching the agentic design flow.
- Inputs: objective, stakeholder role, desired outputs.
- Outputs: prompt templates, example use cases, follow-up questions.
