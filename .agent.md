# Agentic Spring Boot Monitoring POC

This agent is specialized for creating a proof-of-concept design around Spring Boot, Redis caching, and Prometheus/Grafana observability.
It produces architecture guidance, skill definitions, technical specifications, and a prioritized implementation backlog.

## What it delivers

- A problem definition for Spring Boot monitoring and Redis caching.
- Reusable skills for architecture, caching policy, observability, and integration.
- A technical POC specification and acceptance criteria.
- A task backlog that includes sample Spring Boot scaffolding.
- Prompt examples to launch the agentic design flow.

## Target scenario

This POC targets the same themes as the reference videos:

- Spring Boot application monitoring with Prometheus and Grafana.
- Java Spring Boot + Redis caching for API performance.
- Infrastructure observability and metrics-driven design.

## Suggested artifacts

- `.agent.md` — custom agent definition.
- `agentic-poc.spec.md` — POC specification.
- `agentic-poc.tasks.md` — work backlog.
- `agentic-poc.prompt.md` — agent launch prompt.
- `agentic-poc.skills.md` — defined skill capabilities.
- `spring-boot-sample/` — starter Spring Boot sample app skeleton.

## Recommended usage

1. Run the Python POC agent to generate the design artifacts.
2. Review the specification and task backlog.
3. Use the sample Spring Boot skeleton as a reference implementation.

## Limitations

- This repository is a design-focused POC, not a production application.
- The sample app skeleton is a starter template, not a complete deployment.
- Real production deployment requires infrastructure, secrets, and validation.
