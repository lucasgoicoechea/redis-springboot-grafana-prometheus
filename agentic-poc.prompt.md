# Prompt for Agentic POC

Act as an agentic programming designer and create a complete POC for Spring Boot observability and Redis caching.

1. Define the domain and the problem the agent solves.
2. Explain expected value and success criteria.
3. Propose an agent architecture with at least 6 skills.
4. Generate a technical and behavior specification for Spring Boot, Redis, Prometheus, and Grafana.
5. Create a prioritized task backlog.
6. Provide usage examples and prompts for the agent.
